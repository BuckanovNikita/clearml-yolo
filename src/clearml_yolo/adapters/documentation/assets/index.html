    02 · РЕДАКТОР

    Проверьте композицию

    Файлы, данные и обучение проверяются при запуске в терминале.

    Документы YAML

    Первый документ — корневая конфигурация. Имена остальных используются в defaults.

    Одна запись Hydra на строку. Поздние значения имеют приоритет. Не добавляйте shell-кавычки вокруг всей строки.

    Ctrl / ⌘ + Enter

    Рядом с конфигурацией

    Нажмите пример в справочнике, чтобы добавить переопределение. Вложенные значения и списки записываются синтаксисом Hydra.

    Исходная композиция

    Для выбранных команды, модели и профиля; выражения сохраняются.

    Секреты из окружения не подставляются. Предпросмотр не читает датасет и файл аугментаций.
