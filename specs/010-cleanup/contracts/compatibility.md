# Preserved interfaces and acceptance contract

All supported command names, arguments, defaults, public imports/signatures,
configuration keys, JSON-schema metadata, replay payloads, scientific values and
publication ownership remain compatible. The existing export validation method
retains its signature, check order, messages and exact input-presence semantics.

Preview validation reports known missing operation inputs without resolving external
expressions or performing file/model/task effects. Unresolved inputs remain deferred.
Hub publication keeps native discovery, containment, atomicity, validated fallback,
provenance, originals and credential-safe errors.

Test consolidation must map every retained unique scenario to an executable assertion.
The ordinary gate still includes architecture negatives and CPU-DDP. Receipt identity,
dependency-byte checks, staged-view protection, interruption and release recovery
must not be weakened to improve timing. Public metadata and justified small duplicates
are retained instead of silently changing compatibility or ownership contracts.
