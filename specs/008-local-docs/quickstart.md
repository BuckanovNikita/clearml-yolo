# Acceptance quickstart

1. Install from source using the documented uv/dependency procedure.
2. Run `cy-docs --check`; expect successful coverage, asset, link and tutorial validation.
3. Run `cy-docs --no-browser --port 0`, open its printed loopback URL and search `batch`.
4. Select a command/model/profile, edit YAML and overrides, preview, copy and download.
5. Try a missing dataset, environment resolver and invalid search path: data access must
   be deferred, resolver preserved and search path rejected.
6. Run the separate browser suite, compatibility tests, canonical verifier and docs check.
7. Obtain actual YOLO/non-YOLO pipeline and artifact evidence using the end-to-end skill;
   complete paired source/installed CY/queue checks, fresh review and Git-only release.

Evidence and limitations belong in dated files under `evidence/`.
