# Data model

Queue snapshots and durable records retain existing schemas; command accepts pipeline and train, default pipeline. Installation identity includes the Python environment and both installed packages. Shared reservation/guardian generations and lifecycle acknowledgement messages retain their contracts.

RemoteReplay is detached data: remote task identifier, optional canonical run configuration and remote General parameters. Missing canonical and malformed/empty canonical are distinct. Invocation retains runtime-owned task objects; named configuration files retain their existing resolution lifecycle.

Asset descriptions identify backend/preset, canonical source, revision/checksum, filename, local destination and override/access guidance. Resolved provenance contains original URL, path and content hash; executable model copies receive paths while canonical input selectors remain untouched.
