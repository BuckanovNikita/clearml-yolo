# ADR-0205 · Use FCOS with a zero-based foreground vocabulary

FCOS uses the same prepared COCO inputs and letterbox canvas as Faster R-CNN. Its Torchvision head operates on pyramid levels P3 through P7 and takes the number of foreground classes directly. Dataset label zero is therefore a valid foreground class at the native boundary.

CY supplies one anchor size per level and restores predictions to the original image. The FCOS preset selects its own checkpoint descriptor even when it shares a backbone with Faster R-CNN. Its best checkpoint is selected by validation mAP50–95.
