# ADR-0001 · Run the detector pipeline as one experiment

A model owner can train a candidate and follow it through evaluation and reporting under one ClearML task. `cy` composes the stage use cases in order and passes their results directly. It owns the task and the run directory. Each `skip_*` switch removes a stage. For example, `skip_train=true` lets the user supply an existing checkpoint. Skipping comparison can leave a previous comparison manifest available for a report. When training and comparison are skipped and the manifest is absent, the outcome records the report as skipped.
