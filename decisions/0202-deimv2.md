# ADR-0202 · Run DEIMv2 against its pinned upstream source

DEIMv2 needs executable upstream code as well as weights. CY selects a preset from the pinned source tree, builds the native solver for the prepared COCO dataset, and uses the dataset's ordered classes. Training requires a square input divisible by 32 and at least 128 pixels per side. The native recipe accepts one gradient accumulation step.

The selected result is the second-stage best checkpoint when available, otherwise the first-stage best checkpoint. Prediction uses the native postprocessor and rejects changes to NMS IoU and half precision. The large and extra-large presets have a distinct backbone acquisition path.
