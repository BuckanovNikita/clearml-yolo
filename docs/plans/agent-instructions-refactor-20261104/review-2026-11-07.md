`master`) reads "Interruptions and training failures must fail the command in every mode."

task". The spec at `43de5af` (`specs/000-baseline/spec.md:468-470`) still says interruption
errors fail the standalone task and command and that "Fatal interruptions still fail", so the
task-failure requirement for interruptions is narrowed. Suggested owner fix, as a separate
owner-scoped change: restore "the command and task" at the current `SKILL.md:260`. The skill
is outside this review's write scope.
