## Limitations and environment findings

- Native execution used CPU; this change does not establish new GPU evidence.
- Real database tests are opt-in and are skipped in the ordinary isolated unit suite.
- The tested system required an explicitly configured MongoDB URI because the bundled
  MongoDB executable was unavailable. Production use still requires a supported MongoDB
  setup; the integration does not deploy one or launch a UI.
- A real import failure exposed an incompatible GraphQL prerelease selected transitively.
  The dependency now constrains graphql-core to the compatible stable 3.2 series.
- Image contents are assumed immutable at a validated path; CSV hashing does not detect
  image changes. File locking coordinates publishers sharing the same local lock directory.
- Machine-specific logs, task identifiers, and scripts are retained in the global
  environment skill's dated evidence directory, outside the repository.
