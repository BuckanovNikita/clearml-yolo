## Executed command shapes

The dataset and native YAML lived under `$CY_RUN_DIR`. Each shell sourced
`scripts/agent_env.sh release030` with the same pre-exported helper-minted tag.
No credentials were copied to files.

```bash
uv run cy-ground-truth data_yaml="$CY_RUN_DIR/data/data.yaml" \
  output="$CY_RUN_DIR/ground_truth.csv" clearml.task_name=ingestion-fixed
uv run cy run_dir="$CY_RUN_DIR/cpu-verified" \
  ground_truth="$CY_RUN_DIR/ground_truth.csv" \
  train.cfg="$CY_RUN_DIR/native-train.yaml" \
  predict.cfg="$CY_RUN_DIR/native-predict.yaml" \
  clearml.task_name=cpu-final compare.bootstrap_iterations=100
uv run cy run_dir="$CY_RUN_DIR/gpu-verified" \
  ground_truth="$CY_RUN_DIR/ground_truth.csv" clearml.task_name=gpu-verified \
  +train.ultralytics.model=/mnt/wsl/data/nkt/clearml-yolo/yolo11n.pt \
  +train.ultralytics.data="$CY_RUN_DIR/data/data.yaml" \
  +train.ultralytics.epochs=1 +train.ultralytics.imgsz=96 \
  +train.ultralytics.batch=2 +train.ultralytics.device=0 \
  +train.ultralytics.workers=0 +train.ultralytics.amp=false \
  +train.ultralytics.seed=1 +predict.ultralytics.device=0 \
  +predict.ultralytics.imgsz=96 +predict.ultralytics.batch=2 \
  compare.bootstrap_iterations=100
uv run cy-val weights="$CY_RUN_DIR/gpu-verified/detect/train/weights/best.pt" \
  ground_truth="$CY_RUN_DIR/ground_truth.csv" output_dir="$CY_RUN_DIR/val-verified" \
  cfg="$CY_RUN_DIR/native-predict.yaml" clearml.task_name=val-verified
uv run cy-compare baseline_model.task_id=7f493e5143694fba8e4c180df17ca1b3 \
  candidate_model.task_id=887edb5c8bbd492bb716e8d0da3ecea1 \
  ground_truth="$CY_RUN_DIR/ground_truth.csv" output_dir="$CY_RUN_DIR/compare-verified" \
  inference.device=cpu inference.imgsz=96 inference.batch=2 \
  bootstrap_iterations=100 clearml.task_name=compare-verified
uv run cy-report comparison_dir="$CY_RUN_DIR/compare-verified" \
  output_dir="$CY_RUN_DIR/report-verified" clearml.task_name=report-verified
```

Native training YAML contained model, dataset path, epochs=1, imgsz=96, batch=2,
device=cpu, workers=0, amp=false, plots=true and cache=false. Prediction YAML
contained device=cpu, batch=2, imgsz=96 and conf=0.001. Bootstrap iterations=100
keeps this integration fixture small; the public default remains 10,000.
